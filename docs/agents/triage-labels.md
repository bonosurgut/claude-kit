# Статусы триажа

Скилы говорят о пяти стандартных ролях триажа. Этот файл сопоставляет роли со строками, которые
используются в трекере этого репозитория (строка `Status:` в файле тикета `.scratch/<фича>/issues/`).

| Роль в mattpocock/skills | Строка в нашем трекере | Смысл                                          |
| ------------------------ | ---------------------- | ---------------------------------------------- |
| `needs-triage`           | `needs-triage`         | Нужна оценка владельца                         |
| `needs-info`             | `needs-info`           | Ждём от автора недостающую информацию          |
| `ready-for-agent`        | `ready-for-agent`      | Полностью описан, агент может делать без людей |
| `ready-for-human`        | `ready-for-human`      | Делает человек                                 |
| `wontfix`                | `wontfix`              | Делать не будем                                |

Когда скил упоминает роль (например, «поставь метку готовности для агента»), используй строку из этой
таблицы. Свои названия — правкой столбца «Строка в нашем трекере».
