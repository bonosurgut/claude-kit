# Трекер задач: локальные markdown-файлы

Спеки и тикеты этого репозитория лежат markdown-файлами в `.scratch/` (под git).

## Соглашения

- Одна фича — одна папка: `.scratch/<фича>/`
- Спека — `.scratch/<фича>/spec.md`
- Тикеты реализации — по файлу на тикет: `.scratch/<фича>/issues/<NN>-<slug>.md`, нумерация с `01`;
  никогда не один общий файл на все тикеты
- Статус триажа — строка `Status:` в начале файла тикета (строки статусов — см. `triage-labels.md`)
- Комментарии и история обсуждения дописываются в конец файла под заголовком `## Comments`
- Текст спек и тикетов — на русском; у каждой пользовательской истории и тикета — ID `F-xx`,
  продолжая `docs/traceability.md` (см. «Мост со своим процессом» в `AGENTS.md`)
- `.scratch/` живёт в git ветки `feat/v1`, но **не публикуется**: при сборке ветки `publish` папка
  вырезается (`git rm -r .scratch`, порядок публикации — в `CLAUDE.md`). Репозиторий на GitHub
  публичный, спеки и тикеты туда не уходят

## Когда скил говорит «опубликуй в трекер»

Создай новый файл в `.scratch/<фича>/` (папку — при необходимости).

## Когда скил говорит «возьми нужный тикет»

Прочитай файл по указанному пути. Обычно пользователь передаёт путь или номер тикета прямо.

## Операции wayfinding

Используются `/wayfinder`. **Карта** — файл, у которого по одному **дочернему** файлу на тикет.

- **Карта**: `.scratch/<работа>/map.md` (тело: Notes / Decisions-so-far / Fog).
- **Дочерний тикет**: `.scratch/<работа>/issues/NN-<slug>.md`, нумерация с `01`, вопрос — в теле. Строка
  `Type:` — тип тикета (`research`/`prototype`/`grilling`/`task`); строка `Status:` — `claimed`/`resolved`.
- **Блокировка**: строка `Blocked by: NN, NN` в начале. Тикет разблокирован, когда все перечисленные файлы
  в статусе `resolved`.
- **Фронтир**: открытые, разблокированные и никем не взятые файлы в `.scratch/<работа>/issues/`; берётся
  первый по номеру.
- **Взять**: поставить `Status: claimed` и сохранить ДО начала работы.
- **Закрыть**: дописать ответ под заголовком `## Answer`, поставить `Status: resolved`, затем дописать
  указатель на контекст (суть + ссылка) в раздел Decisions-so-far файла `map.md`.
