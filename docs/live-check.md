## Что нашлось и чем закрыто

- **Значок тревоги в строке `ctx`.** Claude Code сам рисует перед строкой любого плагина `⚠ <имя плагина>:`, поэтому
  наш `⚠` при контексте ≥ 60% был неотличим, а слово `ctx` повторялось дважды. Теперь значок 🔴, слово убрано
  (коммит `229523f`).
- **Лишний файл плана.** Фоновый запуск в режиме `plan` оставлял файл в `~/.claude/plans/`; теперь режим `default`
  (коммит `e34bfe0`).
- **Обновление плагина.** `claude plugin update` не подтягивает правки, пока номер версии не меняется (`0.1.0`).
  Перед каждой публикацией версию поднимать; в README — как обновиться.

## Что вживую не проверялось и почему

- **Запасной путь А** (буфер обмена + подсказка) — пришлось бы ломать служебные данные приложения. Доказательство —
  автотесты мода (`plugins/handoff/tests/register.test.ts`, случаи «open вернул 1», «чат не появился за 60 с»).
- **Доводка передачи после падения/перезапуска мода** — доказательство только автотестами.
- **Windows** целиком — нет машины; в README и матрице помечено «не проверено вживую».
